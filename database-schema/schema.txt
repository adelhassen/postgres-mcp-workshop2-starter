payments

payment_id — integer — Unique identifier for the payment.
subscription_id — integer — Foreign key linking to subscriptions.subscription_id.
payment_date — timestamp without time zone — Date when the payment was made.
amount_usd — numeric — The payment amount in USD.
method — character varying — The payment method used (e.g., card, PayPal).

sessions

session_id — integer — Unique identifier for the session.
user_id — integer — Foreign key linking to users.user_id.
session_date — timestamp without time zone — Date and time when the session occurred.
duration_minutes — integer — Duration of the session in minutes.
activity_type — character varying — The main activity performed during the session (e.g., browse, listen, read).

subscriptions

subscription_id — integer — Unique identifier for the subscription.
user_id — integer — Foreign key linking to users.user_id.
plan — character varying — The subscription plan (e.g., free, monthly, annual).
start_date — timestamp without time zone — Date when the subscription started.
end_date — timestamp without time zone — Date when the subscription ended, if applicable.
status — character varying — Current status of the subscription (e.g., active, canceled, expired).

users

user_id — integer — Unique identifier for the user.
signup_date — timestamp without time zone — Date and time when the user signed up.
country — character varying — User's country, based on IP geolocation during signup.
device_type — character varying — The type of device used for signing up (e.g., iOS, Android, Web).
